

# python por ejemplo

## Una solución para el libro [Python Por Ejemplo](https://www.amazon.com/Python-Example-Learning-Program-Challenges/dp/1108716830) de Nichola Lacey 

### En lugar de confundir a los lectores con páginas de jerga técnica abrumadora, este libro incluye 150 desafíos prácticos, poniendo el poder en manos del lector. A través de la creación de programas para resolver estos desafíos, el lector avanzará rápidamente desde el dominio de los conceptos básicos hasta el uso confiado de subrutinas, una interfaz gráfica de usuario y la conexión a archivos de texto externos, CSV y SQL
